# Code of Conduct

NetPulse adopts the **Contributor Covenant, version 2.1** as its Code of Conduct.

The full text is maintained by the Contributor Covenant project and is available here:

- Human-readable: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
- Plain-text source: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.txt>

## Summary

In short: everyone participating in the NetPulse community — through issues,
pull requests, discussions, or any other project space — is expected to act
respectfully and professionally, and to help keep the project welcoming and
harassment-free for people of all backgrounds.

Project maintainers are responsible for clarifying acceptable behavior and may
remove, edit, or reject contributions that are not aligned with this Code of
Conduct.

## Scope

This Code of Conduct applies within all project spaces and in public spaces when
an individual is representing the project.

## Reporting

Concerns about conduct may be reported privately to the NetPulse maintainers by
opening a confidential
[GitHub security advisory](https://github.com/dipak-katariya/NetPulse/security/advisories/new),
which keeps the report visible only to the project's maintainers. All reports
will be reviewed and handled discreetly.
